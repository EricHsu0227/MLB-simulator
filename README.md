# Box Seat Baseball Table

Put every file in this folder on any static web host (GitHub Pages, Netlify,
Cloudflare Pages, or your own server). Open index.html through the host's
https address; it will not run if you double-click the file on your computer.

Quick local test:  python3 -m http.server 8000   then open http://localhost:8000

On a phone, use "Add to Home Screen" to install it like an app. After the
first visit it works offline. Seasons, brackets and the Scorebook are saved
in that browser only.

The cards, ballpark cards and charts come from your purchased Box Seat
Baseball set. Keep the site private (password-protected or unlisted) rather
than publishing it openly.

The previous Diamond Sim project is kept on the `diamond-sim-backup` branch.
